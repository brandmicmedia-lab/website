Design a modern, bold, high-converting digital marketing agency website in Figma for a brand named “Brandmic media”.

Brand Style:
- Bold, minimal, high contrast
- Premium creative agency feel
- Strong pink brand identity (#FF0091)
- Clean white background (#F9F9F9)
- Deep black sections (#000000)
- Large typography with strong spacing
- Grid-based layout (12 column desktop grid)

Typography:
- Headings: Bold, modern sans-serif (like Inter, Poppins, or Satoshi)
- Large hero headline (56–64px)
- Section headings (36–40px)
- Clean readable body text (16–18px)

Layout Structure (Desktop 1440px):

1. Hero Section
- Big bold headline:
  “We Scale Brands That Refuse to Be Ordinary”
- Supporting paragraph
- Two buttons:
   Primary: Pink background (#FF0091), white text
   Secondary: Black outline button
- Right side modern professional image
- Floating review badge card (4.9 rating)
- Soft shadow, rounded 16px corners

2. Stats Section
- 4 equal cards horizontally
- Numbers in pink (#FF0091)
- Light shadow
- Minimal layout

3. About Section
- Split layout (image left, content right)
- 3 feature cards:
   - Pink circular icon
   - Bold number 01 / 02 / 03
   - Short description
- Rounded 20px cards

4. Services Section
- Grid layout (3 columns x 2 rows)
- White cards with shadow
- Pink icons
- Hover state (create variant):
   Background turns black
   Text turns white
   Pink accent glow

5. Growth CTA Banner
- Full width black section
- Big white heading
- Center pink button
- Strong contrast

6. Team Section
- 4 equal cards
- Rounded images
- Pink hover effect on social icons

7. Newsletter Section
- Black background
- Subtle pink gradient overlay
- Email input field
- Pink subscribe button

8. Footer
- Black background
- Pink logo
- White navigation links
- Pink hover state

Design Details:
- 16–24px border radius across components
- Soft shadows (0 10px 30px rgba(0,0,0,0.08))
- Auto Layout used everywhere
- Components & Variants for buttons and cards
- Responsive layout (Desktop / Tablet / Mobile frames)
- Clean spacing system (8px grid)
